# oyeraju

Oye Raju — a full-bleed, single-page chai-tapri radio in the spirit of saloon.wtf and hornokplease.xyz.

90s–2000s Bollywood bangers, played via a floating glass player pill, over a hand-illustrated scene of Raju the tapri waiter and the college crowd hanging out at his stall.

## Run locally
Just open `index.html` in a browser — no build step, no dependencies.

## Deploy
Static site, deploys as-is on Vercel/Netlify/GitHub Pages with zero config.
